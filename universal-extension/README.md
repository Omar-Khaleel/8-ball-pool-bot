# Pool Simple Guider

نسخة بسيطة بلا واجهة وبلا وميض:

- **الخط الأبيض:** اتجاه العصا والكرة البيضاء حتى أول اصطدام.
- **الخط الأخضر:** الكرة الهدف متجهة إلى جيب.
- **الخط الأصفر:** الكرة الهدف ستصل إلى الحافة.
- **الخط الأحمر:** الكرة الهدف ستصطدم بكرة أخرى.

لا تعرض النسخة أرقامًا أو دوائر Ghost Ball أو مسارات بديلة أو لوحة معلومات.

## التثبيت والتشغيل

1. افتح `chrome://extensions` أو `edge://extensions`.
2. فعّل **Developer mode**.
3. اختر **Load unpacked** وحدد مجلد `universal-extension`.
4. افتح اللعبة وانتظر حتى تظهر الطاولة.
5. اضغط أيقونة الإضافة مرة واحدة للتشغيل؛ ستظهر علامة `ON` على الأيقونة.
6. اضغط الأيقونة مرة أخرى للإيقاف.

لا تشغّل الإضافة على صفحة تحقق Cloudflare؛ انتظر حتى تدخل إلى اللعبة.

## طريقة العمل

تقرأ الإضافة أكبر عنصر Canvas ظاهر مباشرة من الصفحة، ثم تكشف الكرة البيضاء واتجاه العصا وأول كرة على خط الضربة. بعد الاصطدام تحسب الاتجاه الأولي للكرة الهدف وتحدد أول نتيجة متوقعة: جيب أو حافة أو كرة أخرى.

لا تستخدم `captureVisibleTab` ولا تخفي طبقة الرسم أثناء التحليل، ولذلك لا يفترض أن ترمش الشاشة.

## حدود النسخة

- تعمل أفضل مع طاولة ثنائية الأبعاد ومنظور علوي.
- التوقع يفترض ضربة مركزية بلا Spin.
- لا يحاكي احتكاك القماش أو مرونة الحواف أو قوة الضربة الخاصة بكل لعبة.
- إذا كانت اللعبة تمنع قراءة Canvas أو تعرض اللعبة داخل بيئة غير قابلة للقراءة، فلن يظهر الخط بدل الرجوع إلى تصوير الشاشة المسبب للوميض.

## التطوير

```bash
node universal-extension/tests/run-tests.js
node universal-extension/tests/precision-tests.js
node universal-extension/tests/simple-core-tests.js
```

الملفات الأساسية:

- `simple-guider.js`: قراءة Canvas ورسم الخطين فقط.
- `simple-core.js`: حساب أول اصطدام والوجهة المتوقعة.
- `precision-vision.js`: تمييز الكرة البيضاء باستخدام شكلها واتجاه العصا.
- `service-worker.js`: تشغيل وإيقاف الإضافة بنقرة واحدة.
